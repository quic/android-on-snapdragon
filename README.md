# Android On Snapdragon

This repository contains Android support libraries and sample applications for Snapdragon platforms.

## Contents

- `video`: Android video extension library, demos, and sample applications.

## Development

Contributors should submit pull requests against the `master` branch. See module-specific README files for build, test, and usage instructions.
