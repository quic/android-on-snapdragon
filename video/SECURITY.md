# Security Policy

## Reporting a Vulnerability

If you would like to report a public issue, such as one with a released CVE number, please open a GitHub issue with enough detail to reproduce and triage the problem.

If you are reporting a not-yet-public, urgent, or sensitive vulnerability, contact Qualcomm Product Security at [product-security@qualcomm.com](mailto:product-security@qualcomm.com) or use the Qualcomm [Report a Bug](https://www.qualcomm.com/company/product-security/report-a-bug) page.

Please include:

- Description of the vulnerability.
- Steps to reproduce.
- Affected versions or branches.
- Potential impact.
- Relevant logs, traces, or screenshots with proprietary, confidential, personal, and internal-only information removed.

## Coordinated Disclosure

We follow a coordinated vulnerability disclosure process. Reports are acknowledged, investigated, remediated, and disclosed according to Qualcomm security guidance and applicable project requirements.
